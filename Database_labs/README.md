# Базы данных

Выполнены лабораторные работы 1–10, вариант 7. Каждая папка содержит отчёт DOCX и исходные материалы в папке `Код`.

## Порядок запуска

1. Установить Microsoft SQL Server Express и подключиться к экземпляру `SQLEXPRESS`.
2. Выполнять SQL-сценарии лабораторных работ в порядке номеров.
3. Для ЛР 5–7 сначала восстановить AdventureWorks2019 скриптом `ЛР_05/Код/00_Восстановление_AdventureWorks2019.sql`.
4. В ЛР 10 сначала выполнить SQL-скрипт, затем открыть `FurnitureApp.csproj` в Visual Studio и запустить приложение.

Для повторного запуска ЛР 7 сценарий пересоздаёт только учебную базу `AdventureWorks_Kashapov`.
